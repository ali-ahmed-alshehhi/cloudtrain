# CloudTrain brand

The logo is a cloud with a small neural network inside. The amber line is the path the network learned, ending in the trained answer.

## Files

| File | Use it for |
|---|---|
| `cloudtrain-logo.png` | Main logo on light backgrounds (slides, README, reports) |
| `cloudtrain-logo-dark.png` | Main logo on dark backgrounds |
| `cloudtrain-logo-stacked.png` | Square spaces: cover slides, profile pictures |
| `cloudtrain-mark.svg` / `.png` | The cloud alone, any size |
| `cloudtrain-mark-dark.svg` | The cloud alone, on dark backgrounds |
| `cloudtrain-icon.svg`, `cloudtrain-icon-512.png` | App and avatar icon (simplified network, readable when small) |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | Browser tab and phone home-screen icons for the portal |

Below about 48 px, use the icon files, not the full mark: the full network turns into noise at small sizes.

## Colours

| Name | Hex | Use |
|---|---|---|
| Baby blue | `#BFE3FA` | Fills and large areas |
| Cloud white | `#F7FBFE` | Page background |
| Steel blue | `#5B8DB8` | Buttons, secondary marks |
| Slate | `#334155` | Text and outlines |
| Honey amber | `#E9A93B` | Highlights only: success, the key number. Never text on white |

## Font

The wordmark is [Nunito](https://fonts.google.com/specimen/Nunito) Black (900), free under the SIL Open Font License. "Cloud" is slate, "Train" is steel blue (on dark: cloud white and baby blue).

## Rules

- Keep clear space around the logo of at least the height of the amber output node times 3.
- Do not recolour, stretch, rotate or add effects to the logo.
- On photos or busy backgrounds, put the logo on a cloud-white or slate panel.
