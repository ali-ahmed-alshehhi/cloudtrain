# 0003 — Node 24 instead of Node 20

- **Status:** accepted
- **Date:** 2026-11-12
- **Decided by:** Ali

## Context
The master plan named Node 20 for the portal. Node 20 reached end-of-life in April 2026 and no longer
gets security fixes. Node 24 is the current long-term-support (LTS) version and is supported by Next.js.

## Decision
Use **Node 24** for the portal, its Dockerfile and CI.

## Why
Security fixes, and it is what the team's machines already have.

## Trade-offs
None known for this project. Any library that only supports older Node versions should be avoided.
